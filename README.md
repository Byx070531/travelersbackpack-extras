# 旅行者背包：扩容升级 (Traveler's Backpack: Extra Upgrades)

> **关于本项目**：本模组由 **AI 编写**（编码代理 DeepSeek Harness / deepseek-v4-flash）。
> 代码、资源与文档均由 AI 生成，人类负责提出需求、测试与验收。欢迎在 Issues 反馈问题。

给 [旅行者背包 (Traveler's Backpack)](https://www.mcmod.cn/class/1732.html) 1.21.11 Fabric 版写的附属模组。
新增 9 种扩容升级插件，放进背包的**升级槽**后，成倍提高单个格子能装的物品数量，同时等比放大背包水槽容量；
下界合金及以上的升级还会把水/岩浆变成无限流体。

- 模组 ID：`travelersbackpackextras`
- 目标：Minecraft 1.21.11 + Fabric Loader 0.19.3 + Fabric API 0.140.0
- 硬依赖：旅行者背包 ≥ 10.11.11、[高级下界合金](https://www.mcmod.cn/class/6438.html)（欧米伽升级需要它的钻石下界合金块）

## 一、九种升级

| 升级 | 倍率 | 单格最大堆叠 | 合成配方 |
|---|---|---|---|
| 木制升级 | ×2 | 128 | 空白升级居中，周围 8 个原木（`#minecraft:logs`） |
| 铜制升级 | ×8 | 512 | 8 个铜块围一圈 + 木制升级 |
| 铁制升级 | ×16 | 1024 | 8 个铁块围一圈 + 铜制升级 |
| 金制升级 | ×64 | 4096 | 8 个金块围一圈 + 铁制升级 |
| 绿宝石升级 | ×128 | 8192 | 8 个绿宝石块围一圈 + 金制升级 |
| 钻石升级 | ×256 | 16384 | 8 个钻石块围一圈 + 绿宝石升级 |
| 下界合金升级 | ×1024 | 65536 | 8 个下界合金块围一圈 + 钻石升级 |
| 究极升级 | ×4096 | 262144 | 9 个下界合金升级在 3×3 工作台里平铺 |
| 欧米伽升级 | ×33554432 | **2147483648** | 锻造台：欧米伽升级模板 + 究极升级 + 钻石下界合金块 |

堆叠倍率同时作用于**物品**和**背包水槽容量**（水槽容量 = 原容量 × 倍率）。

> 倍率乘的是**物品自己的堆叠上限**，所以普通 64 堆叠物品按上表计算；16 堆叠物品（雪球、鸡蛋等）
> 上限是 `16 × 倍率`；不能堆叠的物品（工具、药水等）保持不能堆叠 —— 这个升级是「扩容」，不是「万物皆可堆叠」。

### 叠加规则

- 装在同一个背包里的多个扩容升级，倍率**相乘**。
- 究极升级以下的组合，无论怎么乘都**不会超过 4096 倍**（也就是究极升级的值）。
- 装了欧米伽升级，倍率直接是 33554432 倍；再装第二个欧米伽升级也不会更高（可以装，但没用）。
- **一个背包最多装 3 个扩容升级**。

## 二、欧米伽升级链条

### 附魔钻石金苹果

工作台合成（`D` = 钻石块，`E` = 鞘翅，`A` = 附魔金苹果）：

```
D E D
D A D
D D D
```

食用后的效果（在**原版附魔金苹果的效果基础上**修改）：

| 效果 | 等级 | 时长 |
|---|---|---|
| 生命回复 | **V** | 10 分钟 |
| 抗性提升 | I | 10 分钟 |
| 抗火 | I | 10 分钟 |
| 伤害吸收 | IV | 10 分钟 |
| 创造飞行（新增） | I | **30 分钟** |

创造飞行是真正的「像创造模式一样飞」，但玩家仍然是生存模式：效果结束后飞行能力会被收回。

### 欧米伽升级模板

工作台合成（`N` = 下界合金升级模板，`A` = 附魔钻石金苹果，四角 = 四种盔甲纹饰模板）：

```
幽静 A 恼鬼
 A   N  A
涡流 A 潮汐
```

四角的模板依次是：幽静盔甲纹饰（`silence`）、恼鬼盔甲纹饰（`vex`）、涡流盔甲纹饰（`flow`）、潮汐盔甲纹饰（`tide`）。

### 欧米伽升级

锻造台：**欧米伽升级模板 + 究极升级 + 钻石下界合金块**（`advancednetherite:netherite_diamond_block`）。

## 三、超大堆叠与数字显示

- 一个格子里的真实数量用 `long` 保存（上限 2147483648），界面上的数字只是**显示**。
- 背包里显示的数量会自动缩写：`1000 → 1.0k`、`46587 → 46k`、`1000000 → 1.0m`、`2147483648 → 2.1b`。
  一千以内按原数字显示（`128` 就是 `128`）。缩写一律**向下取整**，不会四舍五入。

### 取下堆叠升级的条件

能不能拆升级，看的不是「有没有超堆叠」，而是**拆掉之后剩下的倍率还够不够装下背包里已有的东西**：

- 每一格需要的倍率 = 该格数量 ÷ 物品自身的堆叠上限（向上取整）。1024 个圆石需要 ×16；64 个及以下不需要任何倍率。
- 只要「剩下的升级相乘后的倍率 ≥ 需要的倍率」，这个升级就可以拆。
- 拆不动时动作栏会告诉你**需要多少倍率、拆了只剩多少**。

例：一格 1024 个圆石（需要 ×16），装了木(×2)、铜(×8)、铁(×16) 三个升级 ——
拆任意一个都行（拆铁剩 ×16、拆铜剩 ×32、拆木剩 ×128，都 ≥ ×16）；
如果只装了木制一个升级就拆不下来（拆了只剩 ×1，那 1024 个就装不回去了）。

### 整理（排序）

整理按钮已经适配超大堆叠：

- 同种物品按**真实数量**合并（`189 + 64` 合成 `253`，而不是各占一格），装满的 64 组也会继续往超堆叠里并；
- 合并受当前升级的单格上限约束，绝不会为了合并而超过上限；
- 总量一个不差，任何一步都不会让物品变多或变少；
- 「按数量排序」与「按名称排序」用的都是真实数量，而不是物理上的 1。

## 四、鼠标与按键操作

以下规则只对**装了扩容升级的背包**（或升级被拆掉、但格子里还留着超大堆叠时）的背包格子生效；
没装升级的背包、以及背包以外的格子，操作方式和原版完全一样。

| 操作 | 效果 |
|---|---|
| 左键 | 取出一组（64 个）到鼠标指针上 |
| 右键 | 取出半组（32 个）到鼠标指针上 |
| Shift + 左键 | 直接提取一组（64 个）到物品栏，点几下提取几组 |
| Shift + 右键 | 直接提取 1 个到物品栏 |
| Alt + 左键 | 先数物品栏有几个空位，然后按空位数提取对应组数，一组填满一个空位（右键无响应） |
| Ctrl + 丢弃键 | 从背包里丢出一组（64 个） |
| Ctrl + Shift + 丢弃键 | 丢出 1024 个（16 组）；不足 1024 个就全部丢出 |
| 数字键 / 副手键 | 往快捷栏搬一组（64 个），不会把整堆搬过去 |
| 中键（创造模式） | 复制一组（64 个）到指针上，**不会**复制整堆的数量 |

> 丢弃键用的是原版的「丢弃物品」按键绑定，不写死成 Q，改过按键的玩家照样能用。

## 五、无限流体（下界合金升级及以上）

装了**下界合金升级或更高**的升级后，水槽的处理方式会改变：

- 水**超过两桶**（> 2000 mB）→ 该栏位变成**无限水**
- 岩浆**超过一万桶**（> 10,000,000 mB）→ 该栏位变成**无限岩浆**
- 药水、牛奶等其他流体**不受影响**，是多少桶就是多少桶
- 静止和流动的水/岩浆都算（管道里可能是流动变体）
- 无限流体不会因为取用而减少，水槽会显示为满的，提示框显示「无限」
- 阈值是**严格大于**：正好两桶水不会触发，再加一点才会
- 这个状态存在流体本身的存量里，所以存档、退出重进、联网同步都不会丢；只有清空才会解除

**取出与收回**：水管（旅行者背包自带的水管物品）在**吸取模式**下右键水源/岩浆源可以把流体收回来 ——
无限水槽也允许这样回收，所以倒到世界里放错了位置可以随时吸回去。倒出去（喷出模式）不受影响。

**清除方法**：鼠标指针移到对应水槽上，按住 `Ctrl + Shift` 再按丢弃键。

## 六、龙鳞与鞘翅

### 龙鳞

- 击杀**玩家复活的**末影龙才会掉落，第一只不掉。判断用的是末影龙战斗自己记着的「这块场地已经打过龙」标记，
  所以首发那只仍然只给龙蛋和成就，龙鳞专属于复活后的重复挑战。
- 每次固定掉 **1 个**；**受抢夺影响**：抢夺的每一级独立判定一次 30% 概率多掉 1 个，
  因此抢夺 III 最多掉 4 个（平均 1.9 个）。
- 掉落直接进击杀者的物品栏 —— 战斗正好发生在返回传送门上方，掉在地上的东西有被传送门卷去主世界出生点的风险。

### 合成表

**海洋之心**（原版没有合成表，这里补上）

```
海晶砂粒    鹦鹉螺壳    海晶砂粒
海晶碎片    下界之星    海晶碎片
海晶砂粒    鹦鹉螺壳    海晶砂粒
```

**鞘翅**

```
末影之眼    海洋之心    末影之眼
幻翼膜      鞘翅        幻翼膜
下界合金锭  龙鳞        下界合金锭
```

> 一次合成实际拿到 **2 个鞘翅**。原因是鞘翅有耐久，原版不允许「又耐久又可堆叠」
> （`Item cannot be both damageable and stackable`），配方结果塞不下 ×2 ——
> 所以第 1 个照常从合成栏取出，第 2 个直接进物品栏。两个都是普通鞘翅：可以分别附魔、分别修复、分别穿戴。
> 在背包的**合成升级**里合成同样有效。

## 七、构建

需要 JDK 21。项目里已经带了 Gradle wrapper：

```powershell
$env:JAVA_HOME="D:\JavaStudy\JDK\jdk-21"
cd "E:\Minecraft\MODS\TravelersBackpackExtras"
.\gradlew.bat build
```

产物：`build\libs\travelersbackpackextras-1.21.11-1.0.0.jar`

开发用的两个开关（已经配在 `build.gradle` 的运行配置里）：

- `-Dtravelersbackpackextras.verifyMixins=true`：客户端启动时立刻加载全部 Mixin 目标，配置写错会当场报错。
- `-Dtravelersbackpackextras.selfTest=true`：服务器启动时打印一份自检报告（倍率、超大堆叠、数字缩写、全部配方是否存在）。

## 八、大整合包下的兼容性

大整合包里 `mouseClicked` 这类屏幕层入口会被多个模组抢（malilib 系、Item Scroller、
Inventory Profiles Next 都会在这一层注入并可能吞掉点击），所以 **Alt+左键是在原始鼠标输入层
（`MouseHandler`）拦截的** —— 那是所有屏幕处理的上游，谁也抢不走。只有「左键按下 + 按住 Alt +
当前是旅行者背包界面 + 指针在背包存储格上」这一种组合会被拦截，其他任何点击（包括没开背包时的
全部点击）都原样放行。

模组启动时会在日志里打印构建号（例如 `[Extra Upgrades] build b8 loaded`），
方便确认加载的是哪一版。

**与「一键背包整理 Next / Inventory Profiles Next」的分工**：IPN 会给每个容器界面都加上自己的一套整理按钮，
旅行者背包界面本来就有自带的整理按钮，两套并存很容易点错 —— 而且只有背包自带的那个按钮认识超大堆叠。
所以打开旅行者背包界面时，本模组会把 IPN 自己的控件从界面上移除（只动 `org.anti_ad.mc.*` 的控件、只在背包界面，
IPN 的鼠标滚轮、锁定格子等功能不受影响）。想用 IPN 官方的方式关掉也可以，在
`.minecraft/config/inventoryprofilesnext/integrationHints/` 里放一个 json：

```json
{ "travelersbackpack": { "com.tiviacz.travelersbackpack.client.screen.BackpackScreen": { "ignore": true } } }
```

## 九、已知限制
1. 装了大容量升级的背包格子上，**拖拽分配**和**双击聚拢**都按原版行为工作（会和 Mouse Tweaks 等模组正常共存）。拖拽经过一个已经超堆叠的格子时，那格会被跳过 —— 原版的拖拽在"收集格子"阶段要求物品组件完全一致，而超堆叠多带一个计数组件，所以它天然不会被拖拽改写（也就不会被压坏）。
   （注意：旅行者背包自己重写了 `moveItemStackTo`，所以 Shift 合并是注入在 `BackpackBaseMenu` 上而不是原版方法上。）
2. 手上拿着**不同种类**的物品左键一个超大堆叠时不会交换（原版会交换）。这是为了避免把 365 个物品静默压成 64 个。先把格子取空再放就行。
3. 超大堆叠只存在于背包内部：任何一次取出最多 64 个，所以物品永远不会以「一格 2000 个」的形式跑到物品栏里。
4. 欧米伽升级的流体倍率非常大（容量上限被限制在 `Long.MAX_VALUE / 4`），水槽界面会直接显示为满。
5. 如果某个背包是在**旧版本**里被拆掉了扩容升级、格子里却还留着超过 64 的物品，这个状态不会被自动清理（清掉就等于删物品）。往里面插回任意一个扩容升级即可恢复正常；现在拆升级已经被拦住，不会再产生新的这种背包。

## 十二、配置文件

首次启动会生成 `.minecraft/config/travelersbackpackextras.json`：

```json
{
  "infinite_fluids": true,
  "apple_grants_creative_flight": true
}
```

| 键 | 作用 | 默认 |
|---|---|---|
| `infinite_fluids` | 下界合金及以上的升级是否让水（>2 桶）、岩浆（>10000 桶）变为无限 | `true` |
| `apple_grants_creative_flight` | 附魔钻石金苹果是否给予 30 分钟创造飞行 | `true` |

改完保存并重启游戏生效。文件损坏或缺少某个键时按默认值运行，不会导致游戏无法启动。
